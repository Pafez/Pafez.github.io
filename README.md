# Personal Portfolio

A personal portfolio website showcasing my projects, technical interests, skills, and experience.

## Stack

* **HTML5** — page structure and content
* **CSS3** — layout, responsive design, animations, and visual styling
* **JavaScript** — dynamic project rendering and interactions
* **GSAP** — scroll-based and entrance animations
* **ScrollTrigger** — scroll-driven animations
* **Google Fonts** — Inter and DM Mono

## Features

* Responsive layout for desktop and mobile
* Animated hero and section transitions
* Interactive project cards
* Dynamic project list generated with JavaScript
* Cursor glow effect
* Scroll-based animations using GSAP
* Minimal dark interface with responsive design

## Structure

```text
.
├── index.html
├── style.css
└── script.js
```

## Running Locally

No build system or dependencies are required.

Open `index.html` in a browser, or serve the directory with any local HTTP server.

The site loads GSAP and Google Fonts through external CDNs.
